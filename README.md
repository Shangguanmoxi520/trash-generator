> **去中心化垃圾生成框架。**

`trash-generator` 專為協助開發者規模化合成低熵值數位廢棄物，徹底解決現代硬體效能過剩的痛點。

---

## 為什麼選擇 Trash Generator？

`trash-generator` 透過重塑數位廢棄物的底層邏輯，提供以下核心價值：

* **極致效能**：單指令單資料優化，能以毫秒級速度執行「什麼都不做」。
* **熵減引擎**：使用偽隨機演算法，確保每次均能快速生成。
* **型別安全**：嚴格遵守靜態型別規範、無副作用函式設計原則。
